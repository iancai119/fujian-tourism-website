# Fujian Tourism Information Network

## Project Overview
This project is a front-end web development prototype designed for the "Fujian Tourism Information Network." It serves as a comprehensive portal to promote tourism in Fujian Province, China. The website features scenic spot guides, rural tourism information, rural revitalization news, and user account management interfaces.

The application demonstrates the use of a responsive front-end framework (Bootstrap) to create a consistent and user-friendly layout across various pages.

## Technical Stack
* **Languages:** HTML5, CSS3
* **Framework:** Bootstrap 3 (Utilized for the grid system, navigation, and UI components)
* **Scripting:** JavaScript, jQuery (Required for Bootstrap interactive components)
* **Layout:** Responsive Web Design (RWD)

## Features
* **Responsive Navigation:** A consistent global navigation bar implemented across all pages, featuring login/registration access and site-wide search functionality.
* **Dynamic Carousel:** The homepage integrates a Bootstrap-based image slider to showcase featured tourist attractions.
* **Grid Layout:** Utilizes the Bootstrap grid system (rows and columns) to organize content, such as image galleries and news lists, ensuring proper alignment on different screen sizes.
* **User Forms:** Includes dedicated pages for User Login and User Registration with styled form input fields.
* **Thematic Sections:** Distinct layouts for different content categories, including "Rural Tourism" (City profiles) and "Scenic Spot News" (Article lists).

## File Structure Description
The project consists of the following key HTML files:

* **index.html:** The main homepage containing the image carousel, hot attraction gallery, and news snippets.
* **jingquzixun.html (Scenic Spot News):** A list view page displaying detailed articles and guides for specific tourist locations.
* **xiangcunlvyou.html (Rural Tourism):** An information page introducing major cities in Fujian (Fuzhou, Xiamen, Zhangzhou, Nanping) with descriptive text and imagery.
* **xiangcunzhenxing.html (Rural Revitalization):** A specialized content page focusing on agricultural and rural development news.
* **denglu.html (Login):** The user authentication interface.
* **zhuce.html (Register):** The new user registration interface.

## How to Run
This is a static web project and does not require a backend server or database configuration.

1.  Download or clone the project repository to your local machine.
2.  Ensure the `lib` folder (containing Bootstrap and jQuery files), `css` folder, and `images` folder are present in the root directory.
3.  Open the `index.html` file in any modern web browser (Google Chrome, Microsoft Edge, Firefox, etc.) to view the application.
